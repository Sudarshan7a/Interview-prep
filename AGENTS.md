## Bangalore Job Market Context (always keep this in mind)

### What high-paying fresher roles actually require:

- **DSA/Problem Solving**: Non-negotiable for product companies. LeetCode Easy/Medium fluency is the baseline. Hard problems matter for FAANG/MAANG.
- **Core CS fundamentals**: OS, DBMS, Computer Networks, OOP — asked in almost every interview.
- **Full stack depth**: Not just CRUD — state management, REST API design, authentication (JWT/OAuth), error handling, form validation, performance.
- **TypeScript**: Now expected at good product companies, not optional.
- **SQL**: Intermediate to advanced queries — joins, subqueries, indexes, query optimization.
- **System Design (basics)**: Even freshers get asked "design a URL shortener" or "design a notification system." Cover the basics.
- **Java or JavaScript backend**: Spring Boot with Java OR Node.js with Express — I am building both.
- **Git and basic DevOps**: GitHub, CI/CD basics, Docker fundamentals — expected in any good tech role.
- **Cloud basics**: AWS (EC2, S3, RDS) or GCP fundamentals — a bonus that differentiates freshers.
- **Communication**: Ability to explain your projects clearly, handle follow-up questions, and think out loud.

### Salary-tier awareness:

- ₹4–7 LPA: Service companies (TCS, Infosys, Wipro base roles) — avoid unless backup
- ₹8–15 LPA: Mid-size product startups, service company elite/digital programs — realistic first target
- ₹15–25 LPA: Strong product companies (Swiggy, CRED, Razorpay, PhonePe, Meesho) — requires solid DSA + projects + CS fundamentals
- ₹25 LPA+: FAANG/MAANG (Amazon, Google, Microsoft) — requires consistent DSA practice + strong system design
